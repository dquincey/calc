# Calc

This is meant to be a calculator inspired by Emacs' **calc**. 
I like the concept of the declare first, do later mindset, where you note down all the values you would need for a certain problem, and then 
rearrange it in order to do things in the right order.
Emacs' calc doesn't *really* emulate this. So I'm gonna try do it myself using **FTXUI** and c++.
<img width="1877" height="975" alt="image" src="https://github.com/user-attachments/assets/4caf9c86-2de9-4eca-a125-d498296fe4e9" />

Problem is, it currently doesn't really do anything. That's because I was initially planning to try to do this in *rust* with *ratatui*. But 
that didn't seem to be as intuitive as I'd hoped (Changed my mind more that half way through). So I'm sticking to c++. It's been kinda slow because I'm still trying to *learn* FTXUI.

So right now it just has a box with a stack and a little text box at the bottom. But you can press **q** to exit!
